метасплоит - фреймворк для пентестинга. самый популярный в индустрии

базовые понятия
exploit - код который использует уязвимость
payload - что выполняется после эксплоита
module - отдельный модуль для конктретной задачи
session - установленное соединение с жертвой

запуск
msfconsole

основные команды внутри     
search <название>           найти модуль
use <модуль>                выбрать модуль
info                        информация о модуле 
show options                показать параметры
set RHOSTS 192.168.1.1      установить цель
run                         запустить
sessions                    список активных сессий
