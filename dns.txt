цепочка dns
ты пишешь example.com -> проверка кеша на твоём устройстве -> спрашивает роутер -> запрос dns сервера провайдера -> в случае незнание запрос корневого ↓
корневой -> знает где com сервера -> туда
↓
знает где google.com -> туда

типы dns записей
A - домен -> ipv4
AAAA - домен -> ipv6
MX - почтовый сервер домена
CNAME - алиас, один домен указывающий на другой
txt - текст использующийся для верификации

nslookup example.com <- dns запрос
dig example.com <- подробный dns запрос

dns зона может утечь и раскрыть все поддомены <- это называется dns zone transfer
