разбивка
- rwx r-x r-x
│  │   │   │
│  │   │   └── остальные (читать, выполнять)
│  │   └────── группа (читать, выполнять)  
│  └────────── владелец (читать, писать, выполнять)
└───────────── тип (- файл, d папка, l ссылка)

r - read
w - write
x - execute


-rw-r--r--   1 sigma sigma   11873328 фев 19 22:19  BA.mp4          - владелец может читать и изменять. другие группы только читать

chmod - изменение прав пользователей
755 - стандарт для исполняемых файлов и папок - rwxr-xr-x
644 - стандарт для обычных файлов
600 - приватные файлы - rw--------

chmod 755 file
chmod 644 file
chmod 600 file
chmod +x file - добавить execute всем
chmod {имя владельца} file - изменить владельца
