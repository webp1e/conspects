запрос                  
GET /page HTTP/1.1      <- метод, путь, версия протокола
Host: example.com       <- к какому серверу
User-Agent: firefox     <- кто делает запрос
\r\n                    <- пустая строка типо конец заголовков
тело запроса            <- для POST запроса сюда пишут данные

ответ
HTTP/1.1 200 OK             <- версия, статус код
Content-Type: text/html     <- тип содержимого
\r\n                        <- конец заголовков
<html>тело ответа</html>    <- тело ответа



статус коды
200           <- удача
301/302       <- редирект
404           <- отсутствует 
403           <- доступ запрещён
500           <- ошибка сервера
