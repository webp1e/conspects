реверс инжиниринг - анализ программы без исходного кода

зачемм нужен
анализ вирусов и малваря
поиск уязвимостей в закрытом ПО 
CTF задания
понять как работает чужая программа

уровни реверса
статический анализ - изучаешь не запуская его
динамический анализ - запускаешь и смотришь что происходит

инструменты статического анализа
file program                тип файла, архитектура
strings program             все строки внутри
hexdump -C program | head   сырые байты в hex      
ldd program                 какие библиотеки использует
objdump -d program          дизассемблер

инструменты динамического анализа
strace program              системные вызовы
ltrace program              вызовы библиотек
gdb program                 дебаггер, по шагам

мощные инструменты
ghidra - декомпилятор от NSA. бесплатный
IDA pro - платный. стандарт индустрии
radare2 - мощный опенсорс

для поиска по файлу strings file | grep -i "Rust\|rust\|rustiz"
если не ищется можно искать вручную trings file | less   (для выхода q)
