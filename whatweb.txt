Что это: Инструмент для определения технологий сайта (CMS, сервер, фреймворки, библиотеки)

Установка:
yay whatweb

Базовые команды:
Команда	Что делает
whatweb http://example.com	Базовое сканирование
whatweb -a 3 http://example.com	Агрессивный режим (максимум деталей)
whatweb -a 3 -v http://example.com	Агрессивный + подробный вывод
whatweb -i urls.txt	Сканировать список сайтов из файла
whatweb --proxy 127.0.0.1:8080 http://example.com	Прогнать через Burp Suite

Полезные флаги:
Флаг	Описание
-a 1-4	Уровень агрессивности (1 — тихо, 4 — очень шумно)
-v	Подробный вывод
-l	Список всех плагинов
--log-json=result.json	Сохранить результат в JSON
--user-agent "Mozilla/5.0"	Сменить User-Agent

Пример вывода:
http://example.com [200 OK] Apache[2.4.41], PHP[7.4.33], HTML5, Title[Home Page]

Когда использовать: Перед атакой — узнать, с чем имеете дело (WordPress? Apache? старый PHP?)
