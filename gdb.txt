gdb - дебаггер который позволяет прочитать бинарный файл

sudo pacman -S gdb  установка

gdb ./test          запуск

run                 запустить программу
break main          поставить точку остановки на main
next                следующая строка
step                войти внутрь функции
print x             вывести значение переменной
info registers      состояние регистров
quit                выйти
